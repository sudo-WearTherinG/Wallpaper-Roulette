# Wallpaper Changer

A small Windows wallpaper changer. Press **Win + W** on the desktop to switch to a random wallpaper.

## Features

- Random wallpaper selection
- `Win + W` to change wallpaper
- Fade transition
- Automatic `Fit` / `Fill` selection
- Monitor-aware cropping
- Caches scaling decisions
- Per-image `Fit` / `Fill` overrides
- Supports `.jpg`, `.jpeg`, `.png`, and `.bmp`
- Portable

## Setup

Steps:

First Install 'AutoHotkey_2.0.26_setup.exe'
https://www.autohotkey.com/ ← Or download latest release.

Then run **WallpaperChanger.ahk** file first.
Then run **install-auto-startup.ahk** file next.
